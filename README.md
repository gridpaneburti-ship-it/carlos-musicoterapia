# Carlos Musicoterapia 🌿

Sitio web dedicado a la musicoterapia, la sanación vibracional y la armonización del ser humano.

## ✨ Características
- **Oasis de Respiración y Armonía:** Ejercicio guiado interactivo (*Inhala... Exhala...*) con campanas tibetanas a 432 Hz, 528 Hz y 639 Hz generadas mediante Web Audio API.
- **Diseño Etéreo y Cálido:** Estética suave en tonos lavanda tenue, melocotón en flor, salvia y oro viejo con efecto *glassmorphism*.
- **Fundamento Terapéutico:** Explicación del impacto de las frecuencias en el sistema nervioso, la memoria afectiva y el desbloqueo emocional.
- **Sesiones y Contacto:** Presentación de modalidades individuales, grupales y acompañamiento a mayores.

## 🚀 Despliegue
Este repositorio está preparado para publicarse con **GitHub Pages** directamente desde la rama `main`.
